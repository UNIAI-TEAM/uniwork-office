# G7-05 Platform & Release Verification Tools (Linux + Committed Browsers)

This directory contains the scripts for **G7-05 W1** (Linux desktop packaging, T1 install/launch/6-fixture/uninstall smoke, T2 signed-out zero-network proof, T5 committed browsers Chrome + Edge, and T6 performance/footprint measurements), structured so later **T3/T4** upgrade-rollback work can reuse the same helpers.

## Scripts

| Script            | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | Exit Marker(s)                      |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| `build-linux.sh`  | Runs `npm run dist:linux` for the checked-out SHA, verifies `.AppImage` and `.deb` in `apps/shell/release/`, and prints artifact paths, byte sizes, SHA-256 digests, and build metadata (`apps/shell/release/g7-05/build-artifacts.json`).                                                                                                                                                                                                                                                                                                      | `BUILD_LINUX_EXIT`                  |
| `t1-smoke.mjs`    | Runs T1 smoke under `xvfb-run`:<br>• `--target deb`: installs `.deb`, verifies `/opt/UniWork Office` and `/usr/bin/uniwork-office`, launches app, waits for shell ready signal (`.tab-bar`), opens all 6 G7-06 fixtures and waits for each editor's document content first paint, closes cleanly, uninstalls `uniwork-office`, and verifies `/opt/UniWork Office` is gone.<br>• `--target appimage`: launches `.AppImage` with `--appimage-extract-and-run` (no FUSE required on cloud VMs) and runs the same 6-fixture open/render/close flow. | `T1_DEB_EXIT`<br>`T1_APPIMAGE_EXIT` |
| `t2-net-zero.mjs` | Launches packaged Linux app with a fresh empty `userData` directory (signed out, no session), opens `fx-docx-report-vi.docx`, edits and saves locally, and closes. Cross-checks:<br>1. `strace -f -s 256 -e trace=connect,sendto` across the whole process tree (`AF_INET`/`AF_INET6` to non-`127.0.0.1`/`::1` or any port 53 DNS including `127.0.0.53`),<br>2. Electron `--log-net-log=<file.log>`, and<br>3. `session.defaultSession.webRequest.onBeforeRequest`.<br>Exits `0` iff 0 outbound requests occur.                                | `T2_NET_EXIT`                       |
| `t6-perf.mjs`     | Report-only measurements across all 6 G7-06 fixtures (median of 3 runs per fixture): launch-to-first-paint of document content, local Save end-to-end time, peak RSS of the entire app process tree (`/proc` sampled every 250 ms), installed app disk footprint, and `userData` / offline library disk size after the run. Writes `t6-perf.json` and `t6-perf.md` comparing against `BENCH-01.md`.                                                                                                                                             | `T6_PERF_EXIT`                      |
| `t5-browsers.sh`  | Runs `npx playwright test -c web/e2e modules-smoke docs-web size-gate open-refused` with `WEB_E2E_REQUIRE_BUILD=1` and `WEB_E2E_CHANNEL=chrome` or `msedge`. Fails if any test is skipped or fails.                                                                                                                                                                                                                                                                                                                                             | `T5_CHROME_EXIT`<br>`T5_EDGE_EXIT`  |
| `self-test.mjs`   | Lightweight local self-test (no Electron/Playwright launch) verifying G7-06 fixture SHA-256 materialization, `strace` and `--log-net-log` parsers, and `/proc` RSS sampling.                                                                                                                                                                                                                                                                                                                                                                    | —                                   |

## Reusability for T3 / T4 Upgrade & Rollback

- `t1-smoke.mjs` accepts `--artifact <path/to/pkg.deb|AppImage>` and `--keep-installed` so T3/T4 scripts can install version `N`, populate `userData`, upgrade in-place to `N+1`, and roll back to `N`.
- `fixtures-data.mjs` embeds gzipped base64 payloads of the 6 canonical G7-06 fixtures (`fx-xlsx-revenue-xyz.xlsx`, `fx-docx-report-vi.docx`, `fx-pptx-deck-vi.pptx`, `fx-pdf-invoice-vi.pdf`, `fx-md-notes-vi.md`, `fx-html-page-vi.html`) and verifies their SHA-256 digests against the G7-06 manifest on every run (or accepts `G7_05_FIXTURES_DIR` override).
