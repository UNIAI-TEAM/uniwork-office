# G7-05 Platform & Release Verification Tools (Linux + Committed Browsers + Upgrade/Rollback Matrix)

This directory contains the scripts for **G7-05 W1** (Linux desktop packaging, T1 install/launch/6-fixture/uninstall smoke, T2 signed-out zero-network proof, T5 committed browsers Chrome + Edge, and T6 performance/footprint measurements) and **G7-05 W2** (T3 upgrade/rollback matrix `N′ → N+1 → rollback N′ → N+1` and T4 pre-guard build `pre-N′` verification).

## Scripts

| Script                    | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Exit Marker(s)                                                 |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `build-linux.sh`          | Runs `npm run dist:linux` for the checked-out SHA, verifies `.AppImage` and `.deb` in `apps/shell/release/`, and prints artifact paths, byte sizes, SHA-256 digests, and build metadata (`apps/shell/release/g7-05/build-artifacts.json`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | `BUILD_LINUX_EXIT`                                             |
| `t1-smoke.mjs`            | Runs T1 smoke under `xvfb-run`:<br>• `--target deb`: installs `.deb`, verifies `/opt/UniWork Office` and `/usr/bin/uniwork-office`, launches app, waits for shell ready signal (`.tab-bar`), opens all 6 G7-06 fixtures and waits for each editor's document content first paint, closes cleanly, uninstalls `uniwork-office`, and verifies `/opt/UniWork Office` is gone.<br>• `--target appimage`: launches `.AppImage` with `--appimage-extract-and-run` (no FUSE required on cloud VMs) and runs the same 6-fixture open/render/close flow.                                                                                                                                                            | `T1_DEB_EXIT`<br>`T1_APPIMAGE_EXIT`                            |
| `t2-net-zero.mjs`         | Launches packaged Linux app with a fresh empty `userData` directory (signed out, no session), opens `fx-docx-report-vi.docx`, edits and saves locally, and closes. Cross-checks:<br>1. `strace -f -s 256 -e trace=connect,sendto` across the whole process tree (`AF_INET`/`AF_INET6` to non-`127.0.0.1`/`::1` or any port 53 DNS including `127.0.0.53`),<br>2. Electron `--log-net-log=<file.log>`, and<br>3. `session.defaultSession.webRequest.onBeforeRequest` (treating all non-`http(s)`/`ws(s)`/`ftp` schemes as internal).                                                                                                                                                                        | `T2_NET_EXIT`                                                  |
| `build-upgrade-matrix.sh` | Builds the 3 Linux x86_64 packages for T3/T4 in `apps/shell/release/g7-05-matrix/`:<br>• `N+1` (`1.0.0-g705n1`, `APP_STORE_LEVEL = 3` via in-place `apply-n1-patch.mjs` on `HEAD` followed by `git checkout --` of the 6 patched files and `git status --porcelain` verification, `.deb` + `.AppImage`),<br>• `N′` (`v1.0.0-beta.3`, `4bdba928d`, `1.0.0`, `APP_STORE_LEVEL = 2`, built in an isolated `git worktree add --detach` with its own `npm ci` and `npm run dist:linux`, `.deb` + `.AppImage`),<br>• `pre-N′` (`v0.11.0-dev.6`, `fcfcd29dd`, `0.11.0`, pre-G5-04g guard, built in an isolated `git worktree add --detach` with its own `npm ci` and `npm run dist:linux`, `.deb` + `.AppImage`). | `G7_05_UPGRADE_MATRIX_BUILD_EXIT`                              |
| `apply-n1-patch.mjs`      | Dependency-free (Node built-in modules only) build-time patch helper that sets `APP_STORE_LEVEL = 3` and version `1.0.0-g705n1` for the synthetic `N+1` package during `build-upgrade-matrix.sh` (never committed to product code).                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | —                                                              |
| `t3-upgrade-rollback.mjs` | Runs the 4-step T3 upgrade/rollback matrix (`N′ → N+1 → rollback N′ → re-upgrade N+1`) on one machine and the same `userData` directory via `sudo dpkg -i` (plus `.AppImage` portable verification in Step 3), recording store SHA-256 digests, `UWS1` headers, `uniworkLocks()` + `.uw-lock-panel` (`#uw-lock-title`, `.uw-lock-body`) S11 refusal UI + screenshot, and `strace` zero-network proof.                                                                                                                                                                                                                                                                                                      | `T3_UPGRADE_EXIT`<br>`T3_ROLLBACK_EXIT`<br>`T3_REUPGRADE_EXIT` |
| `t4-pre-guard.mjs`        | Self-sufficiently prepares (or reuses) an `N+1`-written store (`schema: 2, min_store_level: 3`), installs `pre-N′` (`fcfcd29dd`, `0.11.0`) over it, and verifies the known limit: `parseBinding` rejects `schema !== 1` so the local file does not bind (`uniworkDocStatus === null`), no save intent or `pending-upload.bin` is created (`uniworkSave === null`), `uniworkLocks` is recorded as `'unavailable'`, store SHA-256 digests are untouched, and `strace` records zero outbound / server traffic.                                                                                                                                                                                                | `T4_PRE_GUARD_EXIT`                                            |
| `t6-perf.mjs`             | Report-only measurements across all 6 G7-06 fixtures (median of 3 runs per fixture): launch-to-first-paint of document content, local Save end-to-end time, peak RSS of the entire app process tree (`/proc` sampled every 250 ms), installed app disk footprint, and `userData` / offline library disk size after the run. Writes `t6-perf.json` and `t6-perf.md` comparing against `BENCH-01.md`.                                                                                                                                                                                                                                                                                                        | `T6_PERF_EXIT`                                                 |
| `t5-browsers.sh`          | Runs `npx playwright test -c web/e2e modules-smoke docs-web size-gate open-refused` with `WEB_E2E_REQUIRE_BUILD=1` and `WEB_E2E_CHANNEL=chrome` or `msedge`. Fails if any test is skipped or fails.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        | `T5_CHROME_EXIT`<br>`T5_EDGE_EXIT`                             |
| `self-test.mjs`           | Lightweight local self-test (no Electron/Playwright launch) verifying G7-06 fixture SHA-256 materialization, `strace` and `--log-net-log` parsers, URL scheme classification, `/proc` RSS sampling, `SZV1` / `UWS1` helpers, `apply-n1-patch.mjs`, and static verification that every `aiOffice.<name>` / `aiOfficeTabs.<name>` referenced in `tools/g7-05/` exists in `apps/shell/src/preload/index.ts`.                                                                                                                                                                                                                                                                                                  | —                                                              |
